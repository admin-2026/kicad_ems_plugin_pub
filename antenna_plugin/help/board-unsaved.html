Save the board first

The board open in the editor has never been saved (or its .kicad_pcb file is missing), so there is no file for the simulation to read the physical stackup from.

How to fix it

  1. In the PCB editor, choose File > Save (Ctrl+S). If the board is brand new, KiCad asks where to put the project — pick a folder; the simulation results will be stored next to it in a simulation subfolder.
  2. If you have not configured the stackup yet, do it now: File > Board Setup > Physical Stackup, then save again.
  3. Return to the Antenna Designer window — the banner entry disappears as soon as the saved file is found.
Why the file matters: some KiCad builds ship an incomplete scripting binding for the stackup manager, so the plugin reads the (stackup …) block straight from the saved .kicad_pcb file instead of from the live editor. Until the board exists on disk, there is nothing to read.

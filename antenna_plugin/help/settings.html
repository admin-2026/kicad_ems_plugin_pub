Settings reference

Every knob in the window, what it changes, and what it does when you leave it alone.

Settings are saved per project, in simulation/settings.yaml beside the board, and come back on the next launch. The design form — target, speed, Advanced, the marker picks and the pass knobs — is one value shared by the Simulate tab and every designer tab; a designer's scan rows belong to that designer alone.

Speed / accuracy

One slider over seven stops, fastest to most accurate; it drives the six Optimizations toggles in Advanced, and each stop is captioned with the settings it stands for. Changing a toggle by hand reads Custom. The default stop is Mur ABC · no refinement · conformal · coarse air · 2 cells across driven copper — the cheapest stop that meshes the copper at full resolution. One notch up is the same mesh inside CPML.

Advanced

Every knob in the Advanced pane is one key of the solver's config, and the pane says which, in brackets: an empty field shows it after its default — 0 = auto [cell_mm] — and a tick or a picker carries it greyed beside its label. That key is the name the solver's warnings, its log and the run's config.yaml use, so a message about a knob leads to the field that set it. Typing a value hides the placeholder; the key stays on the field's tooltip. The tables below name each knob the way the window does.

Advanced · Cell size

Two fields, one control: the range the lattice's base cell may take. Left blank, the solver sizes the cell itself — the finer of λ/20 and one Nth of the driven copper (Cells across driven copper, above). The box captions itself with what the pair currently means, and the two fields push that automatic cell in opposite directions.

SettingWhat it doesDefault
Start at (mm)The cell the run starts from. Typing one switches the automatic rule off — neither the wavelength nor the driven-copper term applies any more — so it is the field for a deliberately coarser mesh, and the one that goes stale when the board changes.0 = auto
Never coarser than (mm)A ceiling on that cell: the smallest gap or clearance that has to survive on the lattice. It only ever refines — it joins the automatic rule rather than replacing it, and a ceiling above the cell the rule already picked does nothing at all. It also bounds how far an over-budget re-mesh may coarsen the cell; past the ceiling the run stops.0 = no ceiling

Halving a cell is roughly eight times the cells and twice the steps — about 16× the wall clock — so on a large board a ceiling belongs with the Adaptive mesh tick on, which keeps the copper far from the feed at the cell it had. To coarsen a mesh without throwing the rule away, lower Cells across driven copper instead of typing a start cell: it loosens the copper term rather than deleting it.

Advanced · Markers

SettingWhat it doesDefault
Marker layerThe User layer both the feed marker and the area marker are drawn on, User.1–User.9. User.2
Blank is not empty: a blank field (or a 0) means auto — the solver derives it from the board and the band, and the report says what it resolved to. What is never defaulted is a number about your board: a missing stackup thickness, permittivity or material stops the run instead of being quietly replaced, so the plugin only ever simulates values you actually entered.

Unsaved stackup changes

The Physical Stackup in the editor differs from the one in the saved .kicad_pcb file. The simulation reads the file, so running now would use the old stackup. This is a warning, not a blocker — Run offers to save for you.

How to fix it

  1. Click the banner's Save board button, or save in the PCB editor (Ctrl+S) — either brings the file up to date and clears this warning.
  2. Or just press Run simulation: it prompts with Save & Continue before starting.

Notes

  • Only the stackup is read from the file. Unsaved trace or footprint edits don't trigger this warning — gerbers are plotted from the live board.
  • After the plugin saves on your behalf, KiCad's title bar may still show the * modified marker — the editor keeps its own dirty flag, which a plugin save cannot clear. The file on disk is current regardless.
Why the file is authoritative: some KiCad builds expose no usable scripting API for the stackup manager, so the plugin parses the saved file. Detection errs on the side of warning: prompting to save is cheap, silently simulating a stale stackup is not.

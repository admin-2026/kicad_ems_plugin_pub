Set up the physical stackup

The saved .kicad_pcb file contains no (stackup …) block — Board Setup > Physical Stackup has never been configured (or never saved) for this board.

How to fix it

  1. In the PCB editor, open File > Board Setup > Board Stackup > Physical Stackup.
  2. Check the Copper layers count at the top matches your board (2 for a plain two-sided board).
  3. For every row, fill in a Thickness; for each dielectric (core / prepreg) also set Epsilon R. Picking a Material with the … button fills the numbers from KiCad's material table (FR-4 is the common default).
  4. Press OK, then save the board (Ctrl+S) — KiCad only writes the stackup block to the file on save.
Why there is no default: the simulated impedance and resonant frequency depend directly on the substrate thickness and permittivity. Guessing "typical FR-4" behind your back would produce a plausible-looking but wrong result, so the plugin refuses to run until the real stackup is in the file.

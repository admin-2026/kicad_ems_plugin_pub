Dielectric gap count

The saved stackup does not have exactly one dielectric gap between each pair of adjacent copper layers (a board with N copper layers needs N−1 gaps; a single-layer board needs one substrate under the foil).

How to fix it

  1. Open File > Board Setup > Board Stackup > Physical Stackup.
  2. Read the stack top-to-bottom: between every two copper rows there must be at least one core/prepreg row, and there must be no stray dielectric above the top or below the bottom foil. Several consecutive plies (core + prepreg) between the same two foils are fine — the plugin merges them into one gap.
  3. This state usually appears after changing the copper layer count while the stackup was edited by hand, or after an importer wrote an unusual stack. Adjusting the copper count in Board Editor Layers and letting the Physical Stackup regenerate is the quickest reset (re-enter the thicknesses afterwards).
  4. Press OK and save the board (Ctrl+S).
Why it blocks the run: the simulator builds the vertical grid by alternating foil and substrate exactly as listed. A missing or extra gap would silently shift every layer above it, so the mismatch stops the run instead of producing a subtly wrong board.

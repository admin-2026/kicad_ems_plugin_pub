Dielectric thickness missing

A dielectric (core or prepreg) layer in the saved stackup has no thickness. The banner names the layer, e.g. dielectric 1.

How to fix it

  1. Open File > Board Setup > Board Stackup > Physical Stackup.
  2. Find the named dielectric row and enter its Thickness. Mind sublayers: a KiCad dielectric can be split into several plies (core + prepreg) with the add sublayer control — every ply needs its own thickness. The plugin sums them into one gap.
  3. If you don't have a fabricator stackup sheet: a standard two-layer 1.6 mm FR-4 board has a single ≈1.51 mm core between the two foils. For multilayer boards, use your fab's published stackup — the per-gap thicknesses vary widely.
  4. Press OK and save the board (Ctrl+S).
Why it isn't defaulted: the gap between the antenna layer and its ground is the single strongest knob on the simulated input impedance and bandwidth. A guessed thickness would shift the resonance without any visible warning, so the run stops until the real value is in the file.

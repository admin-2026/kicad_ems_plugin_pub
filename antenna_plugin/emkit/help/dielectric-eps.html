Dielectric permittivity missing

A dielectric layer in the saved stackup has no relative permittivity (Epsilon R, εr) set.

How to fix it

  1. Open File > Board Setup > Board Stackup > Physical Stackup.
  2. In the named dielectric row, either pick a Material with the … button (which fills εr and loss tangent from KiCad's table) or type the value from your laminate's datasheet:
    Laminateεr (typ.)
    FR-44.4 – 4.6
    Rogers RO4003C3.38
    Rogers RO4350B3.48
    PTFE / RT-duroid 58802.2
    Every sublayer (ply) of the dielectric needs a value.
  3. Press OK and save the board (Ctrl+S).
Why it isn't defaulted: the resonant frequency of a printed antenna scales roughly with 1/√εr — the difference between FR-4 (≈4.5) and a PTFE laminate (≈2.2) moves a 2.45 GHz design by hundreds of MHz. A silent guess would be worse than an error, so the run stops instead.

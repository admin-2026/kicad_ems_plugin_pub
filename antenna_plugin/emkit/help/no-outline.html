Board outline missing

The board has no outline on the Edge.Cuts layer (or no enabled copper layer), so the simulator cannot tell where the substrate ends.

How to fix it

  1. In the PCB editor, select the Edge.Cuts layer in the Layers panel (right-hand side).
  2. Draw a closed outline around the design — the rectangle tool (Place > Draw Rectangle) is enough for most boards. Lines and arcs work too as long as their ends meet.
  3. Leave the antenna's keep-out area inside the outline; the outline is the physical board edge, not the copper.
  4. Save the board (Ctrl+S).
Why it blocks the run: the gerber export gives the simulator the substrate shape from Edge.Cuts. Without it there is no dielectric volume to mesh — the run would fail while plotting the gerbers anyway, so it is stopped up front.

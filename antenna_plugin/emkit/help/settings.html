Settings reference

Every knob in the window, what it changes, and what it does when you leave it alone.

Settings are saved per project, in simulation/settings.yaml beside the board, and come back on the next launch — one form for the whole window, whichever page you set a knob on.

That file is also what a run is made of: the command line reads it rather than a window, so a copy of it, edited by hand, is a run (run start --settings my.yaml). This window rewrites its own copy whenever it closes or starts a run — see the Command line guide.

The design form — target, speed, Advanced, the marker picks and the pass knobs — is one value shared by the Simulate tab and every designer tab; a designer's scan rows belong to that designer alone.

Antenna area and feed (designer tabs)

SettingWhat it doesDefault
Feed width / Feed layerShared with the feed marker above; the width also draws this marker's feed triangle. 1.00 mm / top copper
AngleTurns the placed marker about its own centre, in degrees counter-clockwise (0 = as placed): a slider to sweep it round, a box beside it for the exact figure. Any angle: an off-grid one is simulated by rotating the whole board back onto the grid. It is here because KiCad turns a group only by its rotation step — R in the editor still works, and this control follows it. 0° (and whatever the marker on the board reads)

The area itself has no settings here: the rectangle on the board is the setting, which is what the group's name on the canvas (AntennaAreaMarker: double-click to edit the marker) and the line under this box both say. Double-click the marker to enter its group, then drag a corner to size the area — a board rectangle is the one kind of item KiCad's point editor gives handles to — and drag the arrow to the edge the feed should enter from (it is squared back onto the nearest edge, wherever it is dropped). The arrow is a footprint, so it moves in one piece and cannot be pulled apart; the rectangle is kept square whichever way it is dragged. A fresh marker is dropped at the design's suggested size for the target frequency, capped at the Edge.Cuts outline.

Move (M) and rotate (R) the marker with KiCad's own tools. The wizard re-reads it whenever its window regains the focus. Placing a fresh marker resets the scan rows.

Speed / accuracy

One slider over seven stops, fastest to most accurate; it drives the six Optimizations toggles in Advanced, and each stop is captioned with the settings it stands for. Changing a toggle by hand reads Custom. The default stop is Mur ABC · no refinement · conformal · coarse air · 2 cells across driven copper — the cheapest stop that meshes the copper at full resolution. One notch up is the same mesh inside CPML. The slider drives the mesh and nothing else: the solder mask is its own tick in Advanced > Materials, on no stop of this slider.

Advanced

Every knob in the Advanced pane is one key of the solver's config, and the pane says which, in brackets: an empty field shows it after its default — 0 = auto [cell_mm] — and a tick or a picker carries it greyed beside its label. That key is the name the solver's warnings, its log and the run's config.yaml use, so a message about a knob leads to the field that set it. Typing a value hides the placeholder; the key stays on the field's tooltip. The one tick with no key beside it is Simulate the solder mask coating: it decides what the config's stackup holds rather than setting a key of its own. The tables below name each knob the way the window does.

Update and Delete are for your own saved materials — a built-in one can be neither changed nor removed. Metal modelsheet (fast, lossless), sibc (skin-effect loss), slab (volumetric foil). sibc
Solder mask (material row)What the coating is made of, when it is simulated: the board's own εr from the Physical Stackup, one of the built-in coatings, or Custom… — saved and shared exactly like the metals and substrates above, in a list of its own. from board stackup
Simulate the solder mask coatingWhether the coating is part of the board being solved. A run that includes the mask needs a thickness from the board's stackup and an εr from the board or the row above — the pre-flight banner says so before Run. It is the dearest tick on this pane: the coating is meshed at its own thickness, so a 20 µm mask becomes the finest cell the run has and the time step follows it down — often ten times the wall clock of the same run without it. Worth it for the last few tens of MHz of a resonance, which is what the fringing field through the coating moves; leave it off until the rest of the board is right. off

What you save is yours, not the project's, so it lives outside it — in %APPDATA%\kicad-antenna-designer\ (Windows) or ~/.config/kicad-antenna-designer/, one JSON file per kind (metals.json, substrates.json, masks.json, and whatever else this plugin lets you save). Leaving a field blank leaves it blank in the saved entry too.

Advanced · Cell size

Two fields, one control: the range the lattice's base cell may take. Left blank, the solver sizes the cell itself — the finer of λ/20 and one Nth of the driven copper (Cells across driven copper, above). The box captions itself with what the pair currently means, and the two fields push that automatic cell in opposite directions.

SettingWhat it doesDefault
Start at (mm)The cell the run starts from. Typing one switches the automatic rule off — neither the wavelength nor the driven-copper term applies any more — so it is the field for a deliberately coarser mesh, and the one that goes stale when the board changes.0 = auto
Never coarser than (mm)A ceiling on that cell: the smallest gap or clearance that has to survive on the lattice. It only ever refines — it joins the automatic rule rather than replacing it, and a ceiling above the cell the rule already picked does nothing at all. It also bounds how far an over-budget re-mesh may coarsen the cell; past the ceiling the run stops.0 = no ceiling

Halving a cell is roughly eight times the cells and twice the steps — about 16× the wall clock — so on a large board a ceiling belongs with the Adaptive mesh tick on, which keeps the copper far from the feed at the cell it had. To coarsen a mesh without throwing the rule away, lower Cells across driven copper instead of typing a start cell: it loosens the copper term rather than deleting it.

About · Docker

Not a setting about this board — a setting about this machine, which is why it sits on the About page beside the command-line box rather than in Advanced. It is not saved in simulation/settings.yaml and does not travel with the project.

SettingWhat it doesDefault
Run the solver inside a Docker containerEvery run started on this machine — from this window and from the command line — goes through a container that can see only the board's simulation folder and has no network. The simulation itself is unchanged. off (always on, and not changeable, on macOS)
Build image / Rebuild imageOne button, named for what it will do: build the image the container runs — KiCad, this plugin and the solver — or, once one is there, delete it and build it again. Minutes. Rebuild after a plugin update; the plugin's own code is inside it. —

The line under the box says what stands in the way, if anything, and what to do about it. The Container guide button beside them is the whole story; the same page opens from the pre-flight banner when a run is stopped by it.

Blank is not empty: a blank field (or a 0) means auto — the solver derives it from the board and the band, and the report says what it resolved to. What is never defaulted is a number about your board: a missing stackup thickness, permittivity or material stops the run instead of being quietly replaced, so the plugin only ever simulates values you actually entered.

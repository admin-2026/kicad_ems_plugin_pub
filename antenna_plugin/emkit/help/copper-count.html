Copper layer count mismatch

The stackup saved in the .kicad_pcb file lists a different number of copper layers than the board has enabled. This usually happens after changing the layer count without revisiting the Physical Stackup, or without saving afterwards.

How to fix it

  1. Open File > Board Setup > Board Editor Layers and confirm the copper layer count you actually want for this design.
  2. Switch to Board Stackup > Physical Stackup in the same dialog — KiCad regenerates the stackup rows to match the layer count. Re-check every thickness and dielectric after the change, because new rows start empty or with placeholder values.
  3. Press OK and save the board (Ctrl+S) so the corrected stackup reaches the file the simulation reads.
Why it blocks the run: the simulator stacks the copper foils in exactly the order and count the file describes. If the file says two layers while four are enabled (or the other way round), the gerbers and the stackup would describe two different boards — there is no safe way to reconcile them automatically.
